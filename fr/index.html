DeployStage

Une plateforme interne de déploiement, une petite PaaS. On soumet un dépôt Git et un nom : le control plane Spring Boot crée le job Jenkins, provisionne un namespace Kubernetes isolé avec un quota et une network policy, lance le build et le suit jusqu'au statut final.

Toute l'infrastructure est décrite en Terraform sur Azure (AKS, ACR, PostgreSQL managé, une VM Jenkins). Le control plane tourne dans le cluster qu'il gère et expose ses métriques à Prometheus et Grafana.

Détection de fraude bancaire

Une chaîne MLOps complète sur des données de cartes très déséquilibrées, évaluée sur l'AUC-PR plutôt que sur l'accuracy. Le modèle retenu atteint 0,8834, avec une précision d'environ 0,99 et un rappel d'environ 0,81 au seuil optimisé.

Un pipeline Jenkins ré-entraîne le modèle, compare le candidat à celui en production et ne construit une nouvelle image Docker que s'il est strictement meilleur. L'API de scoring FastAPI tourne sur Azure Container Apps, avec un dashboard Streamlit pour les scores de risque et le drift des features.

Projet d'équipe

Okane Transfer, en détail

Okane couvre un transfert du guichet jusqu'au paiement. Un agent l'enregistre entre deux clients, la plateforme le tarifie selon la grille du corridor et génère un code de retrait, et le bénéficiaire encaisse avec ce code. Chaque étape alimente la caisse journalière de l'agent, le journal d'audit et le suivi côté client.

15entités
103endpoints d'API
3rôles
4statuts de transfert

Qui l'utilise

Admin gère le réseau

  • Crée, active et désactive les utilisateurs
  • Agences, pays, devises, corridors
  • Grilles tarifaires : tranche de montant, frais fixes, commission, part agence
  • Tableau de bord et journal d'audit

Agent au guichet

  • Crée des transferts, en espèces ou mobile money
  • Paie un transfert avec son code
  • Annule les transferts en attente
  • Ouvre et clôture une caisse journalière

Client suit son argent

  • Inscription et vérification de l'email
  • Transferts envoyés et reçus
  • Recherche par code de retrait
  • Notifications et assistant de chat en français, anglais et arabe

Cycle de vie d'un transfert

PENDINGcréé + code
paiement par codePAID
annulationCANCELED
expirationEXPIRED
  • Le montant doit être positif, et l'expéditeur ne peut pas être aussi le bénéficiaire.
  • Seul un transfert en attente peut être payé, et un transfert payé ne peut pas être annulé.
  • Chaque transfert conserve ses notifications, ses entrées d'audit et ses mouvements de caisse.

Ingénierie

Spring sans Boot

Spring 6 packagé en WAR pour Tomcat, avec l'initialisation des servlets, la chaîne de sécurité, la persistance et Swagger configurés à la main.

JWT stateless

Un filtre de jeton passe avant Spring Security. Les routes admin exigent ADMIN, les routes agent AGENT ou ADMIN, les routes client CLIENT ou ADMIN.

Règles métier dans les services

Les contrôleurs appellent des interfaces de service au-dessus des repositories Spring Data, avec des DTO de requête et de réponse, Bean Validation et des transactions.

Caisse et audit

Une caisse journalière par agent avec solde d'ouverture et de clôture, des mouvements d'envoi et de paiement, et un journal d'audit consultable par transfert, agent ou agence.

API documentée

SpringDoc génère la spécification OpenAPI et une page Swagger UI, avec une documentation écrite pour les corridors, les devises et les grilles tarifaires.

Version déployée

Hugging Face bloque le SMTP, donc les emails passent par l'API HTTP de Brevo. Les taux de change viennent d'une API externe et sont mis en cache en mémoire.
